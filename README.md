# Pizzeria Palmetto

This project is a Maven-based Java application.

## Technologies

- Java
- Maven
- JUnit

## Project Structure

The project follows a standard Maven project structure.

## Project Classes

- `Pizza` - represents a pizza with its name, size, and price.
- `Customer` - represents a customer with name and phone number.
- `Order` - manages pizzas ordered by a customer.
- `Pizzeria` - manages customer orders.
